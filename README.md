## Coding Style

This repository uses **C# Top-level Statements**, available in modern C# projects. It lets me write executable code directly without declaring a `Program` class or a `Main()` method explicitly.

```csharp
Console.WriteLine("Hello, World!");

string name = "Developer";
int age = 15;

Console.WriteLine($"My name is {name}.");
Console.WriteLine($"I am {age} years old.");
```

Simple, readable, and focused on understanding the fundamentals first.

## My Learning Principles

- **Consistency over speed** — learn at a sustainable pace.
- **Understand, don't just copy** — know what the code does and why.
- **Practice regularly** — solve small problems before moving forward.
- **Learn from mistakes** — debugging is part of the process.
- **Keep improving** — revisit old code and make it better.
